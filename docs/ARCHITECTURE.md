# 实现原理

## 从数据到画面

`main.tsx` 加载 `public/models.json`，以 `unknown` 接收 JSON，经 Zod 校验后交给 `Galaxy`。空数组、重复 ID、未知领域和错误字段类型会显示加载错误。

`Galaxy` 为同一批记录建立两份布局。`domain` 布局以 15 个固定中心形成具有不同倾角的螺旋星系；`function` 布局按功能标签把点放入 7 条同心轨道。每颗星的随机通道由 ID 的哈希确定，改变输入顺序不会改变布局。

`GalaxyRenderer` 将三维坐标经过相机投影后绘制到原生 Canvas 2D。星点按深度从后往前绘制，拾取沿用实际投影位置。画布本身是二维的，空间旋转和透视由代码计算。

## 星系与星环的切换

切换按钮更新 `taxonomy`，随后调用 `renderer.setLayout`。渲染器以每颗星的当前运动位置为起点，以目标布局中的同 ID 坐标为终点，创建 `GalaxyMorph`。

过渡持续 1,680 毫秒。各星点按固定相位错开起飞时间，使用平滑插值和弧形偏移移动，同时插值颜色与透明度。切换不增删记录；再次切换时以当前画面为新起点。系统减少动态效果或全局暂停状态由渲染器统一处理。

`GalaxyMotion` 为各分组保存独立旋转相位。领域星系沿自己的盘面法向旋转，功能星环使用各自的速度和方向。暂停一个分组时，其他分组继续推进。

## 状态与资源

React 维护搜索词、选中记录、分组、分类方式、标签显示和暂停状态。指针移动及逐帧绘制由渲染器完成，避免逐帧触发 React 更新。视口变化通过 `ResizeObserver` 同步尺寸；渲染器随组件卸载释放观察器、事件和动画帧。

背景使用独立 Canvas 绘制稀疏字符流，CSS 径向渐变构成雾光。它不接收指针事件，并在暂停、页面隐藏或离开视口时停止动画循环。此背景为独立版本重新编写，未包含原业务项目中的 React Bits 背景代码。

## 调整入口

- 星系中心、螺旋臂、倾角与星环半径：`galaxy-layout.ts`。
- 默认视角与相机约束：`galaxy-camera.ts`。
- 旋转速度：`galaxy-motion.ts` 和布局中的 `ring.speed`。
- 切换时长与轨迹：`galaxy-morph.ts`。
- 星点与标记配色：`galaxy-theme.ts`；页面主题变量：`style.css`。
- 数据字段和领域约束：`data/models.ts`。

当前示例以 6,895 条记录展示效果。更大数据量需要在目标设备上测量；绘制与拾取均在浏览器主线程执行。
